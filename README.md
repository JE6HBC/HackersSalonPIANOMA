# Hacker's salon @ Onarimon PIANOMA

お酒とAIとコードが交差する、大人のためのハッカーズバー。  
御成門「PIANOMA」を拠点に開催される技術・AI交流イベントの運営リポジトリです。

本リポジトリでは、イベントの開催告知、企画アーカイブ、当日のプログラム管理、およびコミュニティからの企画提案（Pull Request）の受付を行っています。

---

## 🍸 コンセプト

> **「調和とコードが響き合う、大人の夜。」**

世界三大ピアノの名器「C.BECHSTEIN（ベヒシュタイン）」が佇む上質な空間で、お酒を片手にAIやプログラミングを語り、手を動かすオープンコミュニティです。  
数学的・構造的な美しさを持つ「音楽」と「コード」の親和性を味わいながら、初心者からエキスパートまでフラットに交流できます。

- **入退室自由:** 途中参加・途中退出OK。何時に来て何時に帰っても構いません。
- **敷居は低く、知性は深く:** 質問・雑談メインの初心者から、実務課題を持ち込むゴリゴリのエンジニアまで大歓迎。

## 🛠 主なプログラム・開催コンテンツ

毎回のイベントでは、以下のようなコーナーを組み合わせて開催しています。

1. **AIコンシェルジュコーナー（常時開設）**
   - AIメンターが常駐。「プロンプトの書き方」「エラー解消」「ツールの選定」など何でも相談できる駆け込み寺。
2. **課題持ち込み型ハッキング大会**
   - 自作アプリ、業務課題、個人開発のコードを持ち込み、AIや参加者同士でディスカッションしながら解決を目指すセッション。
3. **スピード勝負！早押しAIコード生成バトル**
   - 会場スクリーンにお題を投影し、制限時間内にAIを用いて的確なコードを生成できるかを競うエンタメ大会。
4. **バイブコーディング / アイデアLT**
   - お酒とコーディング、AIセキュリティ、UI/UXデザイン、ピアノ（キーボード）打鍵トークなど、多分野にわたるショートプレゼン。

## 🤝 コントリビューション（Pull Request歓迎！）

本イベントは参加者・コミュニティと共に育てるオープンな場です。以下のようなPull Requestをいつでも歓迎しています。

### プルリク・提案の例
- **企画・競技ルールの提案:** 「こんな早押しお題をやりたい」「一発プロンプト要件達成大会のルール案」など
- **LT（ライトニングトーク）登壇希望:** `events/YYYY-MM-DD/` 内の登壇枠へのエントリー
- **当日のお困りごと・持ち込み課題の事前登録:** `issues/` での事前共有やドキュメント追加
- **ドキュメントの改善:** READMEやガイドラインの誤字修正、改善提案

### プルリクの手順
1. 本リポジトリを Fork
2. ブランチを作成 (`git checkout -b feature/idea-topic`)
3. 該当のファイル（企画案や告知ファイル）を編集・追加
4. コミットしてプッシュ (`git push origin feature/idea-topic`)
5. 本リポジトリに向けて Pull Request を作成
