# Hacker's Bar @ Onarimon PIANOMA

お酒とAIとコードが交差する、大人のためのハッカーズバー。
御成門「PIANOMA」を拠点に開催される技術・AI交流イベントの運営リポジトリです。

このリポジトリには、イベントの**告知・アーカイブ**と、当日会場で使う**システム**が入っています。

🌐 **サイト:** https://je6hbc.github.io/HackersSalonPIANOMA/

---

## 🍸 コンセプト

> **「調和とコードが響き合う、大人の夜。」**

世界三大ピアノの名器「C.BECHSTEIN（ベヒシュタイン）」が佇む上質な空間で、お酒を片手にAIやプログラミングを語り、手を動かすオープンコミュニティです。
数学的・構造的な美しさを持つ「音楽」と「コード」の親和性を味わいながら、初心者からエキスパートまでフラットに交流できます。

- **入退室自由:** 途中参加・途中退出OK。何時に来て何時に帰っても構いません。
- **敷居は低く、知性は深く:** 質問・雑談メインの初心者から、実務課題を持ち込むゴリゴリのエンジニアまで大歓迎。

---

## 🛠 主なプログラム・開催コンテンツ

1. **AIコンシェルジュコーナー（常時開設）**
   AIメンターが常駐。「プロンプトの書き方」「エラー解消」「ツールの選定」など何でも相談できる駆け込み寺。
2. **課題持ち込み型ハッキング大会**
   自作アプリ、業務課題、個人開発のコードを持ち込み、AIや参加者同士でディスカッションしながら解決を目指すセッション。
3. **スピード勝負！早押しAIコード生成バトル**
   会場スクリーンにお題を投影し、制限時間内にAIを用いて的確なコードを生成できるかを競うエンタメ大会。
4. **バイブコーディング / アイデアLT**
   お酒とコーディング、AIセキュリティ、UI/UXデザイン、ピアノ（キーボード）打鍵トークなど、多分野にわたるショートプレゼン。

## 💻 このリポジトリに入っているもの

### サイト・システム

| 画面                 | URL              | 何をするか                                               |
| :------------------- | :--------------- | :------------------------------------------------------- |
| 公開サイト           | `/`              | 開催予定・アーカイブ・AI課題DB・殿堂                     |
| 会場サイネージ       | `/signage`       | 大型スクリーンに「今このプログラム」「卓」「人数」を映す |
| トーナメントタイマー | `/signage/timer` | 早押しバトルのラウンド・休憩・残り時間を管理             |
| 運営コンソール       | `/admin`         | 当日の参加者登録とチェックイン（スタッフ用）             |

### ディレクトリ

```
data/          イベントのデータベース。開催情報・参加者・受賞・AI課題（→ data/README.md）
docs/          設計・運用・方針（→ docs/README.md）
  adr/         「なぜこうしたか」の記録
src/           サイト本体（Astro + TypeScript）
scripts/       検証・雛形生成ツール
.github/       Issue/PRテンプレート、CI、自動デプロイ
```

### 技術的な前提

**外部サービスを一切使わず、GitHubの機能だけで動きます。**
データベースの代わりにGitリポジトリを、管理画面の代わりにPull Requestを使う構成です。
できること・できないことは [docs/architecture.md](docs/architecture.md) にまとめてあります。

```bash
npm ci          # Node.js 24
npm run dev     # http://localhost:4321/HackersSalonPIANOMA/
npm run verify  # PR前のチェック（整形・データ整合性・型・ビルド）
```
