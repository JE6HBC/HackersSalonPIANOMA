# セキュリティポリシー

## 脆弱性の報告

このリポジトリで脆弱性を見つけた場合、**公開のIssueには書かないでください。**

1. GitHubの [Security Advisories](https://github.com/JE6HBC/HackersSalonPIANOMA/security/advisories/new) から非公開で報告する
2. それが使えない場合は、オーナー [@JE6HBC](https://github.com/JE6HBC) に直接連絡する

数日以内に返答します。修正後、報告者のクレジットを（希望があれば）公開します。

## このリポジトリの攻撃面

静的サイトなのでサーバ側の攻撃面はありませんが、以下は気をつけています。

| 箇所                    | リスク                                              | 対策                                                                                                                                                           |
| :---------------------- | :-------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `registration-sync.yml` | 誰でも立てられるIssueの本文がワークフローに流れ込む | 本文はシェルに展開せず環境変数で渡す。取り込むのは表示名・ハンドル・興味のみで、いずれも文字種と長さを制限。反映はPR経由で必ず人がレビューする                 |
| GitHub Actions の権限   | トークンの過剰な権限                                | ワークフローごとに `permissions:` を最小限で宣言                                                                                                               |
| `data/`                 | 個人情報の混入                                      | `npm run validate:data` がメールアドレス・電話番号を検出してCIを落とす。詳細は [docs/policy/privacy.md](docs/policy/privacy.md)                                |
| 会場サイネージ          | 参加者の情報が大画面に映る                          | 表示するのは表示名と人数のみ。`docs/policy/privacy.md` を参照                                                                                                  |
| `admin` 画面            | 誰でもURLを開ける                                   | この画面は**入力補助でしかなく**、データはその端末の `localStorage` にしか残らない。サーバには何も送らない。認証はかけていないので、機微な情報を入力しないこと |

## 秘密情報

- このリポジトリに **APIキー・トークン・パスワードを置かないでください。** 公開リポジトリです
- 必要になった場合は GitHub の Repository secrets を使い、ワークフローから参照します
- 誤ってコミットした場合は、**まず失効させてから** 履歴の削除を相談してください。
  履歴から消しても、その間にクローンされている可能性があります
