## 問題

標準入力から渡されたCSVを、Markdownのテーブルに変換して標準出力に書き出すプログラムを書け。
1行目はヘッダとして扱い、区切り行（`| :--- |`）を自動で挿入すること。

## 制約

- 使用言語：不問
- 外部ライブラリ：不可（標準ライブラリのみ）
- 値にカンマを含むケース（`"a,b"`）も正しく扱えること

## 入力例

```text
name,role,drink
サンプル太郎,guest,"ジン, トニック"
サンプル花子,speaker,ハイボール
```

## 期待される出力

```text
| name | role | drink |
| :--- | :--- | :--- |
| サンプル太郎 | guest | ジン, トニック |
| サンプル花子 | speaker | ハイボール |
```

## 評価基準

| 観点       | 配点 | 説明                                     |
| :--------- | ---: | :--------------------------------------- |
| 正しさ     |   60 | クォート付きフィールドを含め期待どおりか |
| 速さ       |   20 | 制限時間内の提出タイム                   |
| プロンプト |   20 | AIへの指示が再現可能で簡潔か             |

## ヒント

- 自前でカンマ分割すると引用符で壊れる。各言語の標準CSVパーサを思い出すこと。

## 模範回答

```python
import csv, sys

rows = list(csv.reader(sys.stdin))
if not rows:
    sys.exit()

header, *body = rows
print('| ' + ' | '.join(header) + ' |')
print('| ' + ' | '.join([':---'] * len(header)) + ' |')
for row in body:
    print('| ' + ' | '.join(cell.replace('|', r'\|') for cell in row) + ' |')
```

## 解説

ポイントは3つ。

1. **CSVを自前でパースしない。** `csv.reader` に任せればクォート内のカンマは自動で処理される。
   ここを手書きさせると、ほぼ必ず `"ジン, トニック"` で壊れる。
2. **区切り行の列数をヘッダから導出する。** ハードコードするとヘッダ列数が変わった瞬間に崩れる。
3. **セル内の `|` をエスケープする。** 模範回答では `\|` に置換している。テストケースに含まれて
   いなくても、Markdownテーブルを壊さないための定石。

AIに投げるときは「CSVをMarkdown表に変換して」だけでは 1. と 3. が抜けやすい。
「引用符付きフィールドを含むCSVを、標準ライブラリのCSVパーサを使ってMarkdown表に変換。
セル内のパイプはエスケープする」まで書き切れるかが分かれ目。
