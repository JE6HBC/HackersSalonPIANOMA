# ADR-0005: Astro + 素のCSS を使う

- **状態:** 採用
- **日付:** 2026-09-22

## 背景

作るものは3種類あり、必要な性質が違う。

| 画面                                 | 性質                                               |
| :----------------------------------- | :------------------------------------------------- |
| 公開サイト（開催予定・課題DB・殿堂） | ほぼ静的。SEOと読みやすさが大事                    |
| 会場サイネージ・タイマー             | 常時動く。巨大な文字、暗い部屋、数時間つけっぱなし |
| 運営コンソール                       | フォームと一覧。当日壊れたら困る                   |

そして**コントリビューターのスキルがばらばら**で、多くの貢献はコードではなく
`data/` へのコンテンツ追加になる見込み。

## 決定

**Astro（静的出力）+ TypeScript + 素のCSS（カスタムプロパティ）。**

- コンテンツコレクションが Markdown / JSON をそのまま扱い、Zodでスキーマ検証してくれる。
  [ADR-0002](0002-repository-as-database.md) のリポジトリ＝DB構成と噛み合う
- デフォルトでJSを出さない。動きが要るページにだけ `<script>` を書く
- UIフレームワークを入れない。タイマーもサイネージも素のDOM操作で足りる規模
- 色・余白・文字サイズは `src/styles/tokens.css` に集約する

依存パッケージは **Astro と Prettier だけ**。

## 却下した案

| 案                                 | なぜ選ばなかったか                                                                                                   |
| :--------------------------------- | :------------------------------------------------------------------------------------------------------------------- |
| Next.js                            | サーバ機能が主戦場。静的書き出し専用に使うとフレームワークの半分が無駄になる                                         |
| Vite + React SPA                   | コンテンツページまでクライアント描画になる。Markdownの扱いを自前で組む必要がある                                     |
| 素のHTML/CSS/JS（ビルドなし）      | 参入障壁は最低だが、データのスキーマ検証ができない。壊れたJSONが本番に出る                                           |
| Tailwind CSS                       | サイネージは「3m先から読める巨大タイポ」が要件で、ユーティリティの旨みが薄い。依存とビルド設定が増える割に得が小さい |
| React を島（island）として部分導入 | 現状のUIは素のDOMで十分。必要になったら `@astrojs/react` を足せばよく、後戻りできる判断                              |

## 結果

**得たもの**

- 壊れたデータがビルドで止まる（型とスキーマが効く）
- ページの表示が速く、依存が少ないのでメンテナンスが軽い
- コンテンツだけ触る人は、Node.jsを入れなくてもWeb UIからPRを出せる

**失ったもの / 注意点**

- 複雑な状態を持つUIを足すと、素のDOM操作がつらくなる。
  その時は `@astrojs/react` の導入を新しいADRとして提案すること
- Astro固有の書き方（`.astro`、コンテンツコレクション）を覚える必要がある
- GitHub Pages のサブパス配信のため、内部リンクは `href()`（`src/lib/url.ts`）を通す必要がある
