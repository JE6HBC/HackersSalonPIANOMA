# ADR（設計判断の記録）

**ADR = Architecture Decision Record.** 「なぜこうなっているのか」を残す短い文書です。

このリポジトリは色々な人が触る前提なので、あとから来た人が
「なんでこんな面倒なことをしているんだ」と思ったときに、答えが読める状態にしておきます。

## 書き方

新しい設計判断をするときは、`_template.md` をコピーして連番を振り、PRに含めてください。

- **1つのADRに1つの判断。** 大きい判断ほど短く書けるはずです
- **却下した案を必ず書く。** 「なぜそれにしなかったか」が本体です
- **決まったADRは書き換えない。** 判断が変わったら新しいADRを書き、古いほうの状態を「置換」にします
